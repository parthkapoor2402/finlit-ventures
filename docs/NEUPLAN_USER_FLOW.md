# NeuPlan user flow

Hypothesis prototype. Not a measured habit.

1. Tata Neu Home. NeuPlan is one block between the existing tiles and Top Offers. It is not in the bottom nav.
2. Open NeuPlan. First visit shows what it does: plan, stay on top, get it done when Tata can help.
3. See an example, or go straight to setup.
4. Setup, under a minute: what matters this week, an optional note, where they usually stay.
5. The app builds a week from those choices. Demo data stays labelled.
6. The command center shows what needs attention, anything Tata can help with, and the week underneath.
7. A need such as “Replace charger” opens a detail. Croma is offered because the title is an electronic replacement. Explore marks the need as exploring and opens a demo catalogue. Prices are shown as ₹—. Nothing is for sale.
8. A need such as an assignment has no shop. The person marks it done.
9. Each create, complete, and explore writes a notice. The next look at NeuPlan shows what changed. Dismissing it is explicit. Nothing is invented to fill that list.
10. Summary phrases counts the app already has. Gemini may phrase them. If the key is missing, the app writes the note.

Commerce is a resolution layer. It appears only when `suggestResolution` returns a destination for that type and title.
