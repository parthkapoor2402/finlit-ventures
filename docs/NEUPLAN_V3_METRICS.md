# NeuPlan V3 metrics

No baseline is invented. No rate is shown in the product.

## Case target

Youth weekly active users of Tata Neu, treatment versus control, at +15%. This is the case requirement. It is not measured here and it is not rendered in the interface. Current youth WAU is `TBD — REQUIRES TATA INTERNAL DATA`.

## What this prototype can record

Events already go to the local store. V3 adds intent started, intent submitted, moment created, moment viewed, and the existing need, resolution, and commerce events.

A meaningful session is one in which the student submits an intent, keeps a line, explores a stop, or marks a line done. Opening NeuPlan is not enough.

## Not computed

Second-session rate, third-session rate, resolution click-through, and open-to-shop. Those need a denominator this prototype does not have.

## Kill

Stop if the only way to produce a later open is a prompt, a coin, a streak, a seeded class, or a “still open” line the student did not leave unfinished.
